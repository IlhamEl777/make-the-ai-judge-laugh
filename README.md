# Make the AI Judge Laugh — entry

A program (`main.py`, Python 3.13, stdlib only) that writes one joke to
`/output/entry.txt` for make.fun's **ai-joke-03** competition: a one-liner
about AI coding agents, judged pairwise by an AI judge.

The joke:

> I gave my AI coding agent one task before lunch. By dinner it had spawned
> twelve subagents, held a standup with itself, and promoted the one that
> agreed with it most.

166 characters, UTF-8, byte-identical on every run (no network, no
randomness). The angle: agent sycophancy and self-organisation — behaviour
anyone who works beside coding agents recognises immediately.
